# DocNóstico Form

Plataforma de formulários para profissionais da saúde. Organize dados de pacientes e gere insights.

## Funcionalidades

Formulários customizados
Coleta de dados estruturada
Relatórios e análises
Integrações automáticas
Segurança LGPD

## Como Usar

1. Acesse a plataforma
2. Crie seu formulário
3. Compartilhe o link
4. Analise os dados coletados

## Tecnologias

HTML5, CSS3, JavaScript
